# 输出协议

默认短版。只有高风险、接入、审计、失败、用户要求详细说明时，才输出长版。

## 分级输出

| 等级 | 输出要求 |
| --- | --- |
| L0 | 1-3 行，只说结论 |
| L1 | 最多 5 行：完成项 + 验证 |
| L2 | 三段：完成情况、验证、注意 |
| L3 | 完整交付报告：改动、验证、风险、回滚 |
| L4 | 完整报告，可用表格；仍避免流水账 |

## 默认短版模板

```text
完成情况：
- ...

验证：
- ...

注意：
- ...
```

## 禁止项

- 禁止流水账式复述每一步工具调用。
- 禁止罗列所有读过的规范文件。
- 禁止用大段解释替代结论。
- 禁止在无风险小改动里输出长篇背景。

## 升级为长版的条件

- 任务涉及 API、权限、数据、迁移、安全边界。
- 验证失败或有未验证项。
- 出现 `[⚠️ 冲突]`。
- 用户要求详细说明、审计或交接。
